# Bem-te-Vi School – Long-Scroll Educational Website

## Overview
Bem-te-Vi School Website is a visually rich, single-page styled educational website created for a client. The design integrates multiple screen simulations (mobile and laptop) to provide an immersive user experience. Built using **HTML**, **CSS**, and **Bootstrap**, the site features:

- Long-scroll layout with multiple educational sections  
- Scrollable mobile and laptop screen mockups embedded within the page  
- Modern animations and smooth transitions  
- Fully responsive design for desktop, tablet, and mobile  

This project demonstrates front-end skills in creating visually engaging, large-scale single-page websites for clients.

**Note:** This repository is for **learning and portfolio purposes only** and is not intended for commercial use.

## Key Features
- Long-scroll, multi-section landing page with device screen simulations  
- Interactive visual presentation and modern animations  
- Fully responsive layout for all screen sizes  
- Clean HTML, CSS, and Bootstrap implementation for maintainable front-end code  

## Project Goals
- Build an engaging and immersive landing page for an educational brand  
- Create a large-scale single-page structure with device mockups and animations  
- Ensure responsiveness and smooth user experience across all devices
